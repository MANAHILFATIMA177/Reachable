Keyboard and screen reader lab

Put the mouse away. Every widget below uses native HTML first and adds ARIA only where HTML has no equivalent.

Disclosure

Try: Enter or Space on a summary. Native details needs no ARIA.

What is a focus indicator?

The outline showing where keyboard focus is (SC 2.4.7).

Why use a real button?

It gets focus, Enter, Space and a role for free (SC 2.1.1, 4.1.2).

Modal dialog

Try: open, press Tab, then Esc. Focus should return to the opener.

Confirm

Focus stays inside until you close this.

Menu button

Try: Enter or Down opens; Up, Down, Home, End move; Esc closes.

Form validation

Try: submit empty. Focus jumps to the error summary.

Key log

Shows each key and the focused element, to check focus order (SC 2.4.3).
